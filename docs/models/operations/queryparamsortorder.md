# QueryParamSortOrder

Control the order of returned users. **Possible values**: `desc` (default), `asc`.


## Example Usage

```ruby
require "cloudinary-account-provisioning"

value = QueryParamSortOrder::DESC
```


## Values

| Name   | Value  |
| ------ | ------ |
| `DESC` | desc   |
| `ASC`  | asc    |
