# OperationEnum

Specifies the operation to perform. Use `add` to associate or `remove` to disassociate.

## Example Usage

```ruby
require "cloudinary-account-provisioning"

value = OperationEnum::ADD
```


## Values

| Name     | Value    |
| -------- | -------- |
| `ADD`    | add      |
| `REMOVE` | remove   |
